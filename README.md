## 💡 Problem-Solving Approach

For every problem, I try to follow these steps:

```text

        ↓
3. Think about the brute-force solution
        ↓

        ↓

        ↓

        ↓
7. Implement in Java
        ↓
```

## ⚡ Complexity Matters

A solution that produces the correct answer is not always the best solution.

For example:

```text
Brute Force
Time:  O(n²)

Optimized
Time:  O(n)
```

Therefore, I try to understand not only **"Does the code work?"**, but also:

* Why does it work?
* Can it be optimized?
* What is the time complexity?
* What is the space complexity?
* Which DSA pattern is being used?
